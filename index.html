2. 出入境程序與 Visit Japan Web

台灣自動查驗通關 (e-Gate)

免事先註冊！直接於台灣機場/港口通關閘道前，進行「註冊與通關二合一」即時辦理通关。

日本 Visit Japan Web (VJW) 申報

整合「入境審查」與「海關申報」，務必於 入境前 6 小時 完成線上填寫，並將 QR Code 截圖備用！

Visit Japan Web 官方網站 桃機樂桃出境影片教學 樂桃自助報到說明

3. 那霸機場 (OKA) 樓層設施導覽

1F 到達大廳

入境大廳、計程車 / 公車乘車處、旅遊資訊諮詢中心、便利商店。

2F 出境 & 伴手禮

伴手禮街（紅芋塔/黑糖/泡盛）、天橋直通單軌電車站、Airporter Luggage 櫃台。

3F 報到櫃台

國內線與國際線各航空公司（樂桃、虎航、星宇、越捷等）自助報到機與託運櫃台。

4F 景觀餐廳 & 展望台

沖繩麵、A&W 美式漢堡、戶外觀景台（免費俯瞰飛機起降）。

4. 託運與隨身行李注意事項

嚴禁託運 (必須放手提隨身)

• 行動電源、單體鋰電池、數位相機電池。

• 小型打火機 (每人限帶 1 個)。

手提液體與入境違禁品

• 隨身液體單件需 ≤ 100ml，裝入 1L 透明夾鏈袋。

• 嚴禁攜帶肉類製品（香腸、肉乾、加工肉餡）及新鮮水果。
